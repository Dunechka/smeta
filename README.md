# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Для кого:

- Предприниматели — подготовить коммерческое предложение клиенту.
- Офисные сотрудники — составить смету закупки или показать расходы руководителю.

## Файлы приложения

Планируемая структура:

- `index.html` — разметка страницы: поля, список позиций, итог и кнопки.
- `styles.css` — оформление, удобные размеры элементов и адаптация для телефона.
- `script.js` — обработка ввода, расчёт сумм и сохранение результата в PDF.

Сейчас созданы только документы `README.md` и `AGENTS.md`. Файлы приложения будут добавлены по отдельному запросу.

## Как открыть

После создания файлов приложения откройте `index.html` двойным щелчком. Установка программ и запуск сервера не нужны.

## Как проверить

После реализации расчётов добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸. Сумма позиции — 30 000 ₸.
2. Количество — 1, цена — 8 000 ₸. Сумма позиции — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
